The Vault

right digit, right place right digit, wrong place not in the code

How to play

Open the vault with an eight-digit code.

  • Tap the keypad, or just type numbers.
  • After each attempt every digit changes colour.
  • Green: right digit, right place.
  • Gold: that digit is in the code, but somewhere else.
  • Grey: that digit isn't in the code at all.
  • Six attempts. Tap the lightbulb if you want a nudge.
